## 🛰️ Что такое «Поняшина будка»

**Поняшина будка** — небольшой self-hosted сервер для хранения и чтения книг через браузер.

Главная идея интерфейса — не обычный список книг, а полноценная рабочая станция для чтения: каталог слева, книга в центре и инструменты оформления справа.

На большом экране интерфейс повторяет концепцию референса: тёмная синяя панель, фиолетовые акценты, книжный разворот, боковые панели и блок «Аперитив».

На телефоне компоновка перестраивается отдельно: боковые панели скрываются, каталог и читалка занимают всю ширину, а управление переносится в компактную мобильную навигацию.

### Основные области

- **Верхняя панель** — логотип, каталог, написание книг, аперитив, управление пользователями и профиль.
- **Левая «Библиотека»** — поиск, категории, обложки, названия, авторы и количество книг.
- **Центральная читалка** — текущая книга, прогресс, разворот на две страницы и навигация.
- **Правая панель** — темы оформления, конфигурация отображения и «Аперитив».
- **Нижняя часть читалки** — назад/вперёд, ползунок страницы и закладки.

## 📱 Mobile

Мобильная версия не является просто уменьшенной desktop-страницей.

На телефоне:

- боковые панели убираются из постоянной разметки;
- каталог использует всю ширину экрана;
- карточки книг становятся компактными;
- читалка показывает одну страницу;
- крупные desktop-кнопки заменяются иконками;
- профиль остаётся доступен в верхней панели;
- внизу появляется навигация **Каталог / Аперитив / Тема / Профиль**;
- поиск открывается отдельной мобильной строкой;
- учитывается safe-area современных телефонов.

## 🔐 Пользователи и права

| Роль | Возможности |
|---|---|
| 👤 **Гость** | просмотр каталога и доступных книг |
| 📖 **Reader** | чтение, профиль, смена собственного пароля |
| 👑 **Admin** | создание, редактирование и удаление книг; управление пользователями |

Первичный аккаунт:

```text
Логин: admin
Пароль: admin
```

После первой установки пароль администратора следует сменить.

Пароли не хранятся в открытом виде: сервер использует scrypt с солью.

## 🚀 Установка

Проект рассчитан на Ubuntu/Debian и установку напрямую по публичному IP, без обязательного домена.

### Одна команда

```bash
curl -fsSL https://raw.githubusercontent.com/nitrous-beer/ponya-budka/main/deploy.sh | sudo bash
```

После установки:

```text
https://ВАШ_PUBLIC_IP:9443/
```

Используется self-signed сертификат на 365 дней, поэтому браузер может показать предупреждение о сертификате.

### Через Git

```bash
sudo apt update
sudo apt install -y git
git clone https://github.com/nitrous-beer/ponya-budka.git
cd ponya-budka
sudo bash deploy.sh
```

## 🔄 Повторная установка и удаление

`deploy.sh` рассчитан на повторное развёртывание на том же Ubuntu-сервере.

Для полного удаления:

```bash
sudo bash deploy.sh --uninstall
```

Без интерактивного подтверждения:

```bash
sudo bash deploy.sh --uninstall --yes
```

Удаление предназначено только для компонентов Будки: приложения, её systemd unit, конфигурации Nginx, сертификата, данных и созданных этим экземпляром правил UFW.

> ⚠️ Полное удаление удаляет `/var/lib/budka` и `/var/backups/budka`, поэтому вместе с ним удаляются книги и пользователи.

## 🛡️ Безопасность

Предусмотрены:

- HTTP → HTTPS;
- self-signed TLS с IP в SAN;
- HttpOnly + Secure + SameSite=Strict cookie;
- хеширование паролей через scrypt;
- ограничение попыток входа;
- серверная проверка административных прав;
- Nginx reverse proxy;
- отдельный systemd-сервис API;
- серверное хранение книг и пользователей.

Для сервера, доступного непосредственно из интернета, рекомендуется дополнительно использовать firewall и при необходимости VPN или полноценный публичный TLS-сертификат.
